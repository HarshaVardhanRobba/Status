## Do 4 — Linux permissions
Hands-on chmod/chown on a scratch file (and a scratch script) in `/tmp`,
real Git Bash transcript appended to `docs/Week_2/linux-w2.md`. Notable
finding: this Git Bash sits on NTFS, so `chmod 777`/`chmod 755` did not
actually change the reported mode bits (`stat` still read 644 back), and
the scratch script still ran with no `x` bit shown — MSYS infers
executability from shebang/extension, not the mode, on this filesystem.
Logged why repo files are 644/755 rather than 777 (least privilege — do not
hand out write access to everyone by default) and how `umask 0022` produces
644/755 defaults from the 666/777 a program originally asks for. Commit
`321a48b`.
