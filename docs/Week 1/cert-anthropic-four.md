# Anthropic's four Claude certifications

Anthropic runs its certification program through Pearson VUE (proctored via
OnVUE, their online exam-proctoring product). All four exams are proctored —
identity check, screen share, and a 360-degree room scan before you start,
same as any formal certification exam. Passing score is 720 on a 100-1000
scale, for all four.

## The four certifications

| Code | Name | Who it is for |
|------|------|----------------|
| CCAO-F | Claude Certified Associate — Foundations | Everyday practical use of Claude — consultants, project leads, non-engineers who use Claude as a tool day to day. |
| CCDV-F | Claude Certified Developer — Foundations | Engineers building applications on the Claude API: tool use, agents, integration work. **This is the target certification on this track.** |
| CCAR-F | Claude Certified Architect — Foundations | Solution architects who design and build agent systems. Anthropic's first proctored credential, launched March 12, 2026. |
| CCAR-P | Claude Certified Architect — Professional | Advanced credential: integration architecture, governance, and evaluation at enterprise scale. **Post-training credential** — assumes CCAR-F (or equivalent hands-on experience) already in hand, not a starting point. |

## Notes

- Registration and prep courses go through the Anthropic Partner Academy;
  the actual exam is scheduled and taken through Pearson VUE.
- Retake rule if a first attempt fails: wait 14 days for the 2nd attempt,
  30 days for the 3rd, 90 days for the 4th — capped at 4 attempts per exam
  in any rolling 12-month window.
- CCDV-F (Developer — Foundations) is the one relevant to this track: it
  covers the same territory this repo's work already touches — API
  integration, tool use, agent behavior — closer than the Associate exam
  (too non-technical) or either Architect exam (assumes broader system
  design experience CCAR-F/-P are built for).
